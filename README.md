## Investor World of Business
This repo contains a companion app and an amended ruleset for the amazing and extremely well renowned Slovak board game "Investor World of Business".

Download all the files in this repo and open `index.html` in your browser to run the app.

or use on [my website](https://investor.jborcel.com).
